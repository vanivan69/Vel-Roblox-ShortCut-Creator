# Roblox Shortcut Creator (Roblox SCC)

Утилита для быстрого создания ярлыков плейсов Roblox на Рабочем столе с официальными иконками игр.

## 🚀 Возможности
- Поиск плейсов по названию через Roblox OmniSearch.
- Поддержка быстрого ввода по **Place ID**.
- Автокомплит и умные подсказки названий игр.
- Автоматическая загрузка и вшивание иконки игры в `.lnk` файл.

## 🛠️ Установка и запуск из исходников
1. Клонируйте репозиторий:
```bash
git clone [https://github.com/ВАШ_НИК/roblox-shortcut-creator.git](https://github.com/ВАШ_НИК/roblox-shortcut-creator.git)
cd roblox-shortcut-creator

```

2. Установите зависимости:
```bash
pip install -r requirements.txt

```


3. Запустите приложение:
```bash
python main.py

```



## 📦 Сборка в .exe

Для сборки исполняемого файла запустите `build.bat` или выполните команду Nuitka вручную.
